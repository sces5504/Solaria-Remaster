## 六項改動

1. 草原保留已接受的樹柱比例與程序布局。後八地形改大岩脊、巨木、霜晶、殘柱等；減少零碎小障礙，依主題形成岸線／群落／柱廊／曲徑。普通房真掩體約4–12件（依尺寸），王房約6–8件，另外有寬水岸／熔岩岸與留出的跨岸通路。新岸線不允許走入或閃避穿過，飛彈與雷射仍可越過低矮岸線；圖像沿用現有圖集，只調尺寸與接線。入口／出口／中央通路與所有可走區域連通。
2. 嚴格密碼解鎖測試選單，新增本周目跳關，旅程地形／王沿用seed建立與存檔的journey，不重抽、不改周目。
3. 主選單資訊合併進手冊，強調雙元素覺醒（特殊命運牌例外保留）；首局選職前先讀，職業特色精簡。Esc移除舊手札按鈕。
4. 全螢幕側欄參與版面計算，戰場保留8:5；窄畫面隱藏側欄，避免遮蔽。
5. 首周目1–4關總怪池按0.8四捨五入、至少1，HP及精英盾×0.8；包含事件波，第5關與其他周目不減，總房間XP不因怪量降低。
6. 進房按當前等級配置一級XP，清關保底一級；XP卡／裝備與周目加成維持額外收益。無加成首周目31次清關由Lv.1到Lv.32，不反覆結算；跳關沒有跳過房間的獎勵。
