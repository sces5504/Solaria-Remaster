# 素材繪製與匯出紀錄

所有圖像以image_gen原創，參考只使用本專案三風格選樣中的精雕冒險PNG。沒有提取外站或舊作素材。來源RGBA與匯出PNG分開保存，工具pack僅做nearest-neighbour取樣和肖像裁切，不重新繪製、遮罩或補畫。

共同要求：1536×1024、6×4個256格、清楚像素群、暖色左上受光、多階材質陰影、俯視三分之二角度、透明角色／物件／FX背景、各格留透明間距、不加文字／標籤／格線。實際active atlas以128格匯出；主選單1152×768。PNG及JSON來源和SHA256見manifest。

- actors-0：三職業、狼、史萊姆、刀手、弓手、薩滿。各ready／step／attack三姿態；每行兩角色，每角色連續三格。
- actors-1至7：描述逐批存prompt-actors-N.txt，實際身份和格位置由tools/adventure/catalog.json索引。
- world-0／1：九地形的樹／石／柱／池，以及門、治療、XP與初版地面。描述存prompt-world-N.txt。
- effects-first：火舌／火彈／電漿／冰水／秘法／六爆炸階段／煙汽／斬擊／鬼影／盾／符文／隕石／虛空血彈／命中。描述存prompt-effects.txt。短FX擷取發現紫色秘法彈的光暈伸進相鄰爆炸格，因此不能把這張作最終可用圖。
- effects：後續image_gen修整，要求每格32透明像素、縮放／置中單個效果，修正跨格圖像；實際引擎再以明確source rectangles隔開殘留的相鄰光暈，避免裁掉爆炸後期煙塵；六爆炸格改中性白／銀灰／灰煙，保留細緻物質紋理，讓引擎依元素正確染成藍／紫／橘。
- landmarks：事件松樹／禮物／墓碑／南瓜灯／血晶／外星地標／隕坑／軍营／軍旗、日輪封印柱、回血圖騰／血球、七地形旗與三職業瞄準武器。索引landmarks.json。
- menu：無字的暮光冒險像素遠景、成熟橡樹、曲折石徑、湖泊、遠方城堡和柔和自然光，中央留安靜區域供主選單文字。
- floors：實機發現初版岩漿／晶石地面搶眼，另繪全不透明低對比地面24格。前九格九地形、後九格替代款，最後六格邊緣款。小型紋理不超過10%；火山以冷卻灰黑玄武岩／灰燼為主，只一條暗淡細紅裂紋，不作滿地發光網；星界僅少量細星點，無大晶石。鏡像、primary／alternate交替與真實route弱高光均不改碰撞。
- heroes-authored-weapons：三職業與南瓜夥伴四行，各六格ready／左步／右步／attack／hurt／fallen，明確相反腿姿與倒下姿態。
- heroes：後續image_gen只移除前三行前五格的手持武器、維持身形／空握手／盾與像素；第六格倒下時地上武器及整行南瓜劍士保持。正式hero的武器由獨立像素圖隨aim旋轉，避免一個人出現兩把武器。職業選擇肖像仍從authored-weapons匯出，清楚展示職業特徵。

實際有效姿態：60類敵人各3張＋三職業／南瓜4類各6張，共204張原創姿態；六引擎狀態的對映與翻面、蓄力、跳躍、受擊由原核心狀態決定。這不是64類都新增六張獨立手繪的宣稱。
