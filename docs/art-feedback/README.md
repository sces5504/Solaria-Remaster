# 1.1.1 美術回饋修正

主人要求：爆炸減少遮擋、法師與劍士辨識不同、劍勢格擋斬改藍色、逐招修正濫用爆炸、處理怪物鄰格殘片，驗證只針對改動、不反覆跑長套件。

- 爆炸中心尺寸由半徑1.5–1.9倍降為0.9–1.12倍，alpha最高0.48且平方淡出；外圍碎光保留衝擊範圍。週期區域不再疊實心爆炸，光源bloom也減少。
- 法師六姿態與肖像改深色髮型、尖帽、紫袍、銀色星紋。image_gen只重繪法師；精確合成第三列，其他三列保持原PNG。原圖、重繪來源、合成來源與hash皆留存。
- 成功格擋反擊來源144以專用blue-slash／藍色碎光呈現；普攻保持原金白色。敵方具有自身招式名稱的斬擊重新交給既有冰息／藤鞭等呈現，不再被通用劍斬攔截。
- 以來源ID優先、元素及持續／瞬發其次分派呈現；不是將同一爆炸染色。Visual增加可選sourceAbilityId／periodic，舊存檔缺省仍可載入。只傳遞呈現資訊；傷害、碰撞、CD與時序未改。
- 八張怪物atlas載入時逐格識別主要連通本體，隔離遠離本體的鄰格殘片；近旁分離武器和半透明輪廓保留。只在載入時進行，不逐幀重算，原始PNG不覆寫。

## 驗證

本地production build／TypeScript／格式通過。10項相關Chromium：首輪9PASS／1FAIL（同一page重複註冊匯入dialog handler），修正測試helper後只補驗失敗的領域檢查，1PASS24.1秒。其餘九項不重跑。新4項unit通過；完整unit首輪330PASS／1FAIL，5000種seed的既有掉落測試受32worker並行與瀏覽器搶CPU超過5秒；只以1worker補驗該項，1PASS3.6秒，未改測試門檻。

Pages增添明確workflow_dispatch validation選項art-feedback：check／全部unit／格式／build維持，browser只跑上述10項；預設與一般push仍是完整browser。此patch以[skip ci]避免push與PR重複啟動長測試，手動Pages執行本次相關scope。發布與線上核對完成後補記結果，現在不提前冒稱已發布。

PNG來源為本專案image_gen原創，CC0；源檔及manifest記hash。24格專用FXatlas的原始提示是6×4透明格、空心留視線、雪／水／分岔雷電／火鳥／劍氣／星刃／冰火／引力等，原始生成檔完整留存。實機證據見gallery，首輪失敗及補驗log見results。
