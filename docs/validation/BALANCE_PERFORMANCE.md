## 碰撞與物件重用

projectile-sweep／SpatialGrid／全彈ContactQueue已接入正式combat。真接觸時間決定同tick的命中、護盾與無敵，而非陣列先後；圓形精確接觸、矩形slab與邊界、可穿湖、掩體擊碎後再求接觸、穿透與彈射、同tick追加彈均保留。

projectile-pool的WeakMap不進存檔；只在整個接觸queue完成後退役，避免提前重用污染未結算接觸。退役清除全部可選欄位，房間更換也歸池。600個有效彈均移動，沒有刪攻擊或合併來源；退役後可重用600且不新增物件。

Stage採Sprite／BitmapText退休池，最多80／256是閒置快取上限，活躍數量不受此限；每次伤害／回血仍各自有ID和BitmapText。回主選單清空活躍Sprite／文字／位置表，死亡敵人位置亦清除。boss-beams已引用，保留地形各自光束結構及原始預警。

## Cloud Chromium 記憶體與密集場景

10次真正UI開始新局→戰鬥→暫停→返回主選單，CDP GC後JS heap約7.27→7.88MiB。追查暖機，追加30次同流程：後15次範圍約0.155MiB，最終約8.164MiB；回主選單活躍Sprite／文字／位置均0，快取48精靈／2文字穩定。這是Cloud JS heap回歸PASS，尚非真設備GPU記憶體驗收。

600敵彈／12目標／五級分裂鏈與禮物／鬼甲／霜鈴／多職技場壓力PASS其功能斷言：初始600敵彈，峰值654彈、1583獨立傷字、兩場域，逐幀文字數與核心傷字數相等。保護觀測角色與高血目標只用於持續觀察渲染，不能用作通關或平衡。

實際後端是ANGLE／Vulkan SwiftShader，軟體WebGL。10秒量測僅8畫面幀，平均1464ms、P95 1921ms；**這台Cloud軟體渲染的密集场景遠不達60FPS**。沒有刪有效特效、數字或攻擊遮掩結果。相同場景在Apple M1級GPU連續60秒驗收仍NOT_RUN，不能把功能PASS改寫為效能達標。

失焦暫停後1.2秒核心不前進；恢復第一幀時鐘歸零、不補打普攻，PASS。首次恢復測試錯把Playwright自動click花費約500ms當第一幀，改取原生click後首個RAF；遊戲也明確重設lastTime。匯入取消恢復按鈕可用、等待舊saveChain後才覆蓋import，PASS。

證據：results/s13-restart-memory-10.json、s13-restart-memory-30.json、s13-dense-webgl.json／png、s13-long-memory-browser.log、s13-memory-focus-cancel-3-browser.log、s13-dense-browser.log。
