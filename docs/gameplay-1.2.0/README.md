Boss 近戰追擊停止距離由 160 改為 110（草原導航目標由 185 改為 80）；有近戰動作的九隻後段地形王基礎行走增加 18%，狼王 85→100、山羊王 48→57、霜鈴老人 80→94、索拉里斯 65→77。其餘遠程王及固定食人花不一律加速。近戰範圍按定位增加約 15–28%，Boss HP 未加厚。

普通衝刺碰牆停止；反彈衝刺反射實際合法分量。多段衝刺完成前段後才取新目標，再保留至少 0.5 秒鎖向預警。初次預警 0.8 秒不縮短；旋轉雷射每束預告至少 0.8 秒，按自身開始時間旋轉，不能在预告期間偷轉或因施放者死亡突然消失。

地雷由王身邊 130 改為玩家鎖定位置外圍 215，保留 1.3 秒武裝、近距觸發與有限自爆；落雷本來就鎖玩家，確認後保留並驗證遠離王時的實際威脅，沒有改成王腳邊雷。環彈仍完整圓，四柱封印 60 度例外不變。600 敵彈仍整組延後，不刪既有有效彈。

所有 Boss 召喚的**戰鬥小怪**都以實際普通怪類型建立精英：HP = 同類一般精英 HP × 2 = 同類普通 HP × 5，套相同地形及周目生命係數；傷害 ×1.4，抽符合定位的精英能力。食人花召喚花怪使用彈幕型生命及 AI，不再套狼類型。召喚上限、零 XP／裝備、15% 獨立補包及王死消失維持。回血圖騰、可攔截血球和封印柱是原有目標物，保留各自規格；不套一般戰鬥小怪公式。

劍士全方向格擋窗口與無敵 0.6→0.9 秒；首次成功後保護 0.4→0.75 秒，結束取兩者較晚。反擊仍成功後 0.3 秒、只一次、揮出當下瞄準，原傷害／來源分類／5 秒 CD 不變。

## 保存與來源修正

schema 維持 1。新 `BossAttack` 可選編排欄位及 `Area.beamMotion` 都可序列化，舊檔可缺省。current／entry 中的舊戰鬥召喚怪按受傷比例遷移，不復活、不增加裝備、不重抽旅程 RNG；精英能力缺省用 ID 專流補齊。舊已生成攻擊依保存的編排自然結束，後續新招使用 1.2.0；舊旅程、Boss 抽選、20 耐久掩體、250 南瓜及永久收藏維持。

核驗交錯時發現彈體的專屬招式 ID 原本取施放者第一個活躍模式，會把第二招畫成第一招。改以彈體自己的 wave ID 取來源，保留既有對應素材及來源語義；兩模式對照回歸，不以此擅改傷害分類。

自動案例證明幾何、時序、來源、召喚、存檔与操作。不是人工自然通關或全部招式逐幀驗收。真 GPU 60 FPS、Firefox／Safari、三職自然 30＋1／高周目平衡及人工聆聽仍 NOT_RUN，原 SwiftShader 密集 60 FPS FAIL 保留。
