## 2. 操作、戰鬥舞臺與流程

[使用者明示／後續覆蓋] WASD 移動，滑鼠瞄準，按住左鍵普攻，**左鍵保持時仍可按右鍵施放職業技能**；空白閃避，E 拾取／進門，I 清關整備，C 構築資訊，Esc 暫停。F 是舊檔案用法，已被 E 取代。進門必須 E，不自動離場；清算完仍可普攻／職技。戰鬥可 E 拾取入揹包，但穿戴／卸下／丟棄只在清關。選卡／暫停／測試對話方塊停止世界；失焦自動暫停且需手動繼續，恢復不補射、不自動用保持按鍵選卡。

[程式事實] 固定世界 1024×640，8:5，全房顯示，桌面適應可用高度且不需滾輪。入口約 (112,320)，出口 (928,320)；邊界與安全生成區依 geometry/world 實際數值。UI 舊 (912,320) 是待對照的舊呈現座標，不能當作新使用者指定值。右門提示約 x>872、abs(y−320)<55；物品 E 拾取距離 64，按最近者且用穩定 ID 決定同距離順序。敵人不互相硬擋友軍投射物；地形阻擋規則按高／低地形區分。

Run phase 是 ROOM_INTRO→COMBAT→SETTLEMENT→UPGRADE_CHOICE→POST_CLEAR→下一房／RUN_END，另有 DEAD。UI 的選單／選角／暫停／圖鑑／確認／測試是外層 screen，不應硬說全在 Run FSM。清怪當幀清算先回復、給 XP 與計分，再判死亡；普通回最大 HP 10%，Boss 回滿當前可回復上限。XP／補包以 1.1 秒可見吸附過程完成後才跳三選一。裝備留地；殘留投射物、光束、區域自然結束仍能傷人，清關不新發動機關攻擊，障礙仍在。不能因美術或清關便利偷偷刪除有效危險。

## 4. 傷害與觸發規則：不可偷改的核心

護甲乘 `100/(100+armor)`。先護盾後 HP；護盾分段獨立過期，溢傷進 HP；真正喫到傷害（包含先扣盾）後玩家有 .5 秒保護，DOT／地形／光束也遵循，不把它混同格擋或控制免疫。敵攻不暴擊。基礎暴擊 15%，未來霜鈴護符改 25%；相對暴率加算後乘基礎、上限 100%；暴傷基礎 1.5、增量加算。

一般傷害順序按原文：等級後基傷×來源副鏈縮放×全域／唯一 basic 或 skill／符合元素標籤的增傷及明寫條件，再暴擊、潮濕、護甲、減傷、盾、HP。basic 與 skill 不同時套用；雙元素不重複喫通用元素加成。百分比傷害只受 sourceScale，不喫甲、暴擊、吸血或一般全域加成；仍先盾後 HP。吸血只按實際 HP 損失，不按盾／溢傷／零傷。

DamageContext 必須保留 owner、source、rootAttackId、kind、tags、critEligible、lifestealEligible、basicHitProxy／basicCastProxy、觸發 ancestry 與 chainScale。主攻／技能／獨立週期場與共振可按規格暴擊；DOT／追加／鏈不能因共用函式變成全部暴擊。副鏈子女保持來源折扣、只套一次，不能回滿倍率或重複折扣；分裂主一支＋副 2／3／4 支，副係數 20／17.5／15%，同次施放仍一個根 ID；同敵各種計數需根 ID 去重。反射 70% 原傷，不算施放；反擊 basicHitProxy、不另算 basicCast。基礎行星爆沒有元素時不偷偷附元素。

牆／樹／巖等高掩體阻擋投射物／光束，低水域不擋；爆炸／圓形 AOE 不因障礙遮住目標。碰撞爆點應是實際撞點。不能為改善美感取消預警、刪有效子彈、把傷字合併、默改來源分類或讓追加無限套娃。規格容許交錯模式，**不是保證每一種彈幕都必有無傷通道**；不能重新提出把所有招式取消或加人工缺口來保證安全。

## 3. 房間流程、死亡與存檔

每周目六個地形，各四個普通房加一個地形 Boss 房，共 30 關，再進獨立最終 Boss 房。第 2／3／4 地形在周目開始時分別隨機選分支，進入時才揭曉。每周目重新隨機。

普通房以一次配置為主，部分有事先預告的有限增援。所有預定波次和一般召喚怪清完才能清算。地形 Boss 死亡時其召喚物消失、不額外掉落，立即清算。

清算吸取所有非裝備掉落。普通房回復最大生命 10%；Boss 房回到當前可回復上限。地上裝備留下供 F 拾取。已有彈幕、雷射及傷害區域自然結束，仍能傷人；場地機關不再發起新攻擊，不可步行地形和障礙保留。

升級獎勵延後到清算完畢。逐級暫停三選一，每次套用後才抽下一組。所有世界計時暫停，選完才恢復。門開後可直接離場，原房攻擊不追到下一房；不能回頭，未拾裝備離場放棄且不提示。

玩家與最後敵人在同次結算都歸零時，先套用清算回血，之後仍歸零才死亡。普通死亡重置等級、卡片、元素、裝備與背包，保留圖鑑、成就、外觀與紀錄；全部玩法內容一開始進池，沒有永久能力加成。

通關後顯示感謝字幕「製作者：Mori Fang」，世界暫停，選結束本局或下一周目。下一周目保留本局全部成長，回暮光草原。最終 Boss 完成同時傷害及清算判定後才顯示字幕。

存檔採房間檢查點：戰鬥中退出回該房入口，沿用該房佈局、敵人與掉落隨機結果。清算和選卡完成後自動存檔。審查規格再補充：每次選卡、清算後拾取／丟棄／換裝也交易式保存，存下待選卡組及清算狀態；重載不刷卡、不能複製裝備。第一版存檔在本機瀏覽器，採版本化資料及匯出／匯入備份，不做跨裝置雲存檔。

## 4. 傷害、暴擊、觸發與防禦

## 10. 執行規範與邊界

### 時間、狀態與結算

全部戰鬥使用秒與固定60Hz步進，暫停凍結模擬時鐘、子彈、狀態、冷卻、召喚復活與傷害字；不使用牆鐘讓戰鬥計時偷偷流逝。按鍵失焦時清除held輸入，恢復不補射、不瞬移。

每步先處理命令與技能狀態，再更新移動／投射物／場地，依命中時間與穩定ID排序處理傷害。第一個有效受傷立即開0.5秒保護；後續同時命中不瞬間疊傷。敵人死亡／召喚消失及房間完成在本步傷害後判定；玩家生命最低0，同步最後敵死亡先清算回復，再判死亡。不可先播放死亡而後又救回。房間完成、回復、XP及掉落各只發一次事件。

狀態：MENU、CLASS_SELECT、ROOM_INTRO、COMBAT、SETTLEMENT、UPGRADE_CHOICE、POST_CLEAR、TRANSITION、RUN_END、DEAD。暫停是overlay，不替換底下phase；升級／裝備／失焦的多個pause reason全部解除才繼續。選卡時不能操作戰鬥或穿戴；POST_CLEAR可開裝備，關閉後殘留攻擊恢復。DEAD與RUN_END不能同時成立，先走已定義的同時清算判定。

冰凍／暈眩禁止移動及新的主動操作，已有彈道與場地攻擊不刪除；獨立自動週期能力按其規則繼續。Boss控制抗性拒絕新控制、不免疫傷害；現有控制自然結束。凍結期間的冰霜再次達門檻，小怪刷新3秒，Boss仍走遞減，不能用光環跳過抗性。

同類燃燒不疊加，刷新時間；強弱來源並存時只取當下最高有效強度，強來源保有自己的3秒期限，弱來源不能無限延長強傷。副箭派生倍率隨傷害來源保存，不受新一次命中重設。

回血上限：一般為最大生命；吸血鬼為已計算最大生命40%。所有補包、清算、Boss回滿、吸血、復活／載入都尊重上限。生命百分比傷害以被打目標當前實體maxHP為基準，三條血各有自身maxHP；分裂體以各自maxHP計算。百分比不能暴擊、吸血或乘一般增傷。

### 普攻代理與施放事件

快射每箭是一次普攻施放代理，副箭／副彈／折射不再增加施放計數。隕落星核是命中代理，不是施放代理。類別傷害加成與命中觸發資格獨立：快射使用職業技能傷害類別，但享有普攻狀態／計數；隕落星核使用普攻傷害類別。格擋反擊用技能類別與普攻命中代理，不增加普攻施放計數。行星爆是無元素技能首段。

左鍵元素招式在真正普攻施放且自己的interval就緒時觸發，快射普攻代理也能檢查此條件；同時副箭不重複檢查。所有右鍵元素按整次職業技能一次發動。右鍵未就緒不消耗任何能力，不排隊自動補施放。指定位置超射程夾到最遠落點，可放不可站立的地面，但不能生成到世界外。

暴擊資格、吸血資格、附加元素狀態、普攻命中代理、施放計數、追加資格是不同旗標。冰矛等元素追加可附自身基礎狀態，但不能因此讓其追加傷害重新觸發自己。燼火爆炸不加火層；已確認的一層追加特例保留。全能力事件攜帶rootAttackId、ancestry及sourceScale，禁止同能力在同一鏈重入。

### 隨機、存檔與資料

周目路線／模板／敵人／裝備用獨立seed stream，裝備以敵ID固定，改變擊殺先後不重抽其裝備。普通補包用該房入口的全局counter與kill-ordinal stream，重玩同序列不重抽。選卡合格池可因已選卡改變，但已呈現選項保存在checkpoint，reload不能重抽。

存檔包括版本、runId、class、周目、房間、route、seeds、卡片／等級、XP、裝備／背包ID、事件已遇集合、補包counter、待選卡、清算旗標。COMBAT重載入口快照；POST_CLEAR重載已保存的清算／掉落與殘留危險快照，不再次回血給XP。拾取／丟棄／換裝交易式保存，同物件不能同時在地上及背包。匯入只驗證資料，不執行內容。損壞回退上一有效版本並提示；禁止默默清空永久資料。

第一版單人，不做登入／伺服器存檔。新局覆蓋未完run必須確認；不能把「繼續周目」當新局。永續記錄與run分離，死亡只清run。

# ARCHITECTURE — 技術與資料架構

2026-10-11，CONFIRMED。以GAME_SPEC的玩法與數值為權威。

## 選型

沿用Node24、npm及package-lock、TypeScript、Vite、Vitest、Playwright Chromium、Prettier。新增PixiJS v8依賴於開發S01，安裝時確認相容並鎖定實際版本；本次文件提交不安裝遊戲依賴。正式畫面用WebGL，無WebGPU或Canvas fallback承諾。Pixi負責視覺，戰鬥核心不可import Pixi／DOM／音效。

選擇理由：固定全房、高頻彈幕、原創atlas與程式特效需要掌握批次繪圖；獨立核心也支援確定性測試與未來合作。代價是自行整合輸入、音效、場景與生命週期，已納入分階段計畫。

## 預定目錄

- src/main.ts：啟動／DI／資源完成後載入menu。
- src/game/core：clock、state、commands、events、rng、room FSM。
- src/game/systems：movement、collision、combat、effects、skills、progression、loot、settlement。
- src/game/entities：player、enemy、boss、projectile、area、companion、obstacle。
- src/game/data：cards、equipment、biomes、roomTemplates、enemy／boss／event definitions。
- src/game/persistence：schema、migration、checkpoint、profile、import/export。
- src/input：鍵鼠與held state，只產生命令。
- src/render：Pixi application、scene layers、atlas、animation、particles、lights、damage text。
- src/ui：menu、HUD、cards、inventory、stats、pause、end、tutorial、catalog。
- src/audio：音效混音、volume、mute，預留music channel。
- src/i18n：穩定key與zh-TW字串。
- public/assets：原創PNG atlas、metadata、音效與來源／授權清單。
- tests/unit、tests/browser：純規則與真瀏覽器測試；不用試玩page替代核心測試。

## 模擬與事件

固定步進1/60秒。command包含tick、actorId、intent、pointerWorld，輸入與state可序列化。PlayerAttack、SkillCast、Dodge、Interact各經能力／phase／control／CD驗證才發出事件。排程用simulation時間；暫停不累積catch-up backlog。

狀態保存runId、class、level、XP、cards map、elements、fusion、stats ratings、equipment IDs、bag slots、room／wave／phase、route seeds、RNG streams、event seen set、drop counter。房間state保存entity table、effects、projectiles、obstacles durability、pending emissions、settledOnce與upgrade queue。render讀快照與一次性事件，不寫HP／卡池／掉落。

DamageContext必含sourceAbilityId、ownerActorId、rootAttackId、damageKind、elementMask、canCrit、lifestealEligible、basicEffectMask、basicHitProxy、basicCastProxy、procPolicy、ancestry、chainScale。子傷害不盲目copy父暴擊資格，按定義重建；保留chainScale。爆血percent獨立kind，不走一般增傷。

施放計數只由BasicCastEvent推進；副箭、折射不發該event，快射每箭發。右元素只由整次ClassSkillCast發。所有傷害觸發只走一個dispatcher，加入回入檢查；同一動畫不能在不同系統重複給傷害。

## 碰撞、地圖與AI

32×20格、格32，邊界牆與高度阻擋。circle／segment檢測，連續sweep避免700速度穿薄牆。雷射掃到第一高度實體截斷；爆炸與地面範圍不做遮蔽。lake／lava是walkBlocked但projectileBlocked=false。

空間網格供近鄰／範圍／鏈目標，結果依距離及ID排序以便重現。敵尋路在模板grid上，掩體碎裂更新通行圖；不能卡死在孤島。普通敵軟分離，boss指令制攻擊排程遵守同時mode上限。玩家與南瓜對敵target選擇使用合法最近距離，無全場強制嘲諷。

地圖seed只選完整驗證模板及允許的變體。path validation失敗重試有限次後用該地形已知合法模板；不改seed去重抽已決定裝備。

## 統計與數值

原始加成同類相加，類別加成與一般全域因子各一次；技能／普攻類別唯一，元素標籤有兩個也不雙乘通用元素傷。derived stat單一函式服務核心與資訊頁。CD存施放時間／deadline或正規化work units，不靠UI進度條算。臨時buff生滅即重算真實速率，不補打歷史攻擊。

所有每級傷害增量、第五級機制封頂、第六級後邊際規則由資料函式表達，不複製到UI。副鏈折扣在DamageContext最末套一次。命中／施放／週期打擊／附著跳傷的分類以GAME_SPEC為準。

## 保存與生命週期

IndexedDB內run與profile分離，用revision及transaction保存；settings小型音量設定可獨立儲存。保存入口快照及最近有效clear checkpoint。每次選卡、clear後拾取／丟棄／換裝持久化。同一物品ID只允許一位置，重新讀取以revision合併而不是重新生成。

載入先schema validate→version migration→invariants→resume phase。重複舊tab以run revision提示使用最新或放棄舊操作，禁止兩tab複製同物品。關頁/失焦觸發暫停與可持久化工作；COMBAT reload從已保存入口，不能把未結算獎勵帶走。

格式損壞／quota不足顯示明確訊息，保留上一份，提供可複製備份；不靜默覆寫profile。匯入JSON只讀白名單schema，無腳本／HTML執行。存檔無圖片，產物assets版本hash與run schema分開。

## 渲染與音效

邏輯1024×640、8:5等比fit容器，不拉伸座標；pointer透過inverse scale轉世界座標。像素sprites nearest，程式light可用linear低解析render target。layers：terrain→obstacles→actors→friendly effects→hostile danger→damage numbers→HUD，敵方危險不能被華麗全屏shader覆蓋。

投射物／粒子／數字物件池，atlas批次與bitmap數字字形；不為每彈創建filter。敵彈預算600通過延後整組新模式發射實現，不刪已有效彈。裝飾粒子最多2000可回收。傷害數字仍每次獨立，不合併或偷刪。GPU和CPU測量分別記錄。

音效由事件映射，只解鎖一次AudioContext；音量／靜音跨局保存。預留music channel但不放背景音樂。

# UI_UX_SPEC — 介面、美術與互動

2026-10-11，CONFIRMED。玩法依GAME_SPEC；下列佈局與特效是已接受總審查的細節，不新增玩家操作限制。

## 畫面流程

主選單→新局確認／三職業選擇→房間簡介→戰鬥→清算→逐級選卡→清關自由拾取／裝備→右門→下一房。最後Boss→完成結算→暫停感謝字幕→結束或下一周目。死亡→結算紀錄→主選單／新局。繼續讀取最後合法checkpoint。新局覆蓋未完run需明確確認。

主選單入口：新局、繼續（無存檔禁用並顯示原因）、圖鑑／成就、音量／靜音、製作資訊。三職業顯示名稱、稱號、普攻／技能、操作說明；不鎖職業。第一局教學提示WASD、瞄準、左右鍵、空白、F、右門，能跳過與重看。

## 戰場與HUD

1024×640固定全房，舞台8:5等比縮放、保留黑邊，指針以真實舞台rect校正。左112,320出生，右912,320門。頂層半透明板避開主要戰區，不新增房外資訊條。

- 左上(12,12)：HP、護盾、Lv與XP，吸血鬼不可回復段以灰色顯示，不能只畫40%似乎受傷。
- 上中(512,12)：地形／周目／房間；Boss血條放其下，階段切換與無敵明示。三條血各獨立階段標籤。
- 右上／邊角：元素、融合、狀態、禁用原因、詞條圖示。
- 房間詞條入場顯示名稱與效果兩秒後縮圖示；可hover看內容。
- 職業CD：角色腳側下方偏移(0,22)，寬40高5、高對比細邊，ready亮邊且音效提示；不能擋角色中心和敵彈。進度用實際剩CD，格擋窗口另用角色輪廓。

傷害數字每次獨立，從命中點偏移6–18單位，約.45秒淡出；暴擊較大但不遮敵彈，治療綠、盾傷淡青、百分比爆血獨特紅burst。font數字atlas，不能合併高頻傷害。

## 選卡與裝備

三選一卡片並排，同屏稀有度／名稱／來源類別／觸發／目前等級／下一級；可看已選與元素、不能退出取別件裝備改抽卡。選擇後套用再抽下一組。鍵盤左右與Enter、滑鼠點擊可用，避免按住左鍵戰鬥轉卡時誤選：開UI後需新的按下事件。

裝備窗口僅POST_CLEAR，戰鬥時快捷鍵提示需先清關。三個裝備欄、12背包格、地上物品清單及丟棄動作；裝備提示只顯示詞條實際值與固定能力，不顯示穿戴後數值預覽。資訊面板另外看實際攻擊次數、CD、暴擊率等。背包滿顯示文字並把物品留地，不替換。滑鼠拖動或選格＋明確穿戴／丟棄，避免失焦誤刪。禁用armor／slot給清楚紅卡原因。

地上橘／紅發光及不同光柱，文字顯示名稱／色；F取最近，距離相同用穩定ID。XP／補包近距自動拾取，沒有成長拾取半徑。

## 暫停、結局與錯誤

感謝字幕必須包含製作者：Mori Fang，顯示本局職業、等級、周目、通關時間與選擇。選下一周目保持裝備構築；結束保存永久紀錄並清run。未處理完同時死亡判定不能先顯示勝利。

存檔／匯入／資源載入失敗明確可重試，不能把失敗顯示成新遊戲成功。無WebGL提示設備／瀏覽器不支持並保留存檔，不假裝遊戲載入。音訊尚未解鎖不阻遊戲，以首次用戶開始動作解鎖。
